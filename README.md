# 聖誕跨年大禮包－澳男請上鉤 🎣🎄

2026/12/22（二）– 2027/1/2（六）伯斯＋雪梨，四人自助旅行的行程網站。
手機、電腦都能用，一個網址就看得到行程、憑證、天氣、分帳，四個人的修改即時同步。

---

## 🔐 登入
- **釣別針登入**：四個人各有一枚澳洲動物琺瑯別針（袋鼠、無尾熊、短尾矮袋鼠、鴨嘴獸），在水面上漂。按住水面拖著磁鐵靠近自己的別針，吸住後會捲上來，再輸入自己的密碼（也可以直接點別針，磁鐵會自己去釣）。
- **只要登入一次**：同一支手機會記住登入狀態，之後打開直接進去。
- **換人／登出**：按右上角自己的頭貼。
- **內容加密**：沒有密碼的人打開網址，只看得到登入畫面。

## 🧭 頂端列（每一頁都看得到）
- **我的帳**：顯示「都結清了 ✓」、「還要付 NT$…」或「要收回 NT$…」，點一下就到結算頁。
- **＋ 快速記一筆**：隨時新增一筆花費，預設幣值是澳幣。

## ☀️ 今天
依照時間自動切換內容：
- **出發前**：倒數到桃園集合的天數、各地天氣預報（出發前 16 天開始有預報，之前顯示 12 月歷年平均）、檢查清單還剩幾項。
- **旅途中**：依當地時間（伯斯、雪梨時差自動處理）顯示「現在」在做什麼、還剩幾分鐘，「下一站」和一鍵導航，今天要記得的已訂行程與備註，今天稍後的行程，以及當地今天的天氣和逐時預報；降雨機率高時會提醒帶傘。
- **回國後**：提醒把帳結清。

## ✈️ 交通住宿
- **機票**：五段航班卡片（航班號、起降時間、航廈、飛行時間），每段都能展開看該段的行李額度；上方「顯示行李額度」可以一次看國泰與澳航的託運、手提、個人物品限制；另有訂位代號、建議幾點到機場、時差提醒。
- **住宿**：三間住宿的入住／退房時間、怎麼進門、確認碼、電話、取消規定和注意事項，一鍵 Google Maps 導航。
- **租車**：取還車時間地點、營業時間、電話、車型與方案、押金與當場要付的費用、要帶的證件、櫃檯推銷保險怎麼回、在澳洲開車的注意事項。
- **憑證**：分成「住宿／交通／活動」三區，每張憑證有自己的圖示、日期、訂單代號和重點提醒，點「開啟」直接看雲端上的憑證檔。

## 🗺️ 行程
- **行程細節**
  - 先選「伯斯」或「雪梨」，再從時間軸點日期；選定那天會亮起，下方用關鍵字標籤列出當天重點。
  - 每一站有時間、停留多久、地點、說明、備註、已訂／已購票標示，以及 Google Maps 導航、在大地圖上看、相關連結。
  - 移動段會顯示交通方式和車程；跨時區的項目會標出是哪裡的時間。
  - 旅途中會畫出「現在」線，已經過去的行程自動淡化，正在進行的會被框起來。
  - **口袋名單**：還沒決定的餐廳列成清單，可以看地圖；大家喜歡哪間就按 👍，會顯示誰按了讚。
  - **編輯行程**：四個人都能新增、修改、刪除、調整順序，也能從口袋名單選定「就這間」；改完大家馬上看得到。
- **地圖總覽**：Google 地圖內嵌，可切換西澳／雪梨；點清單裡的景點地圖就會跳過去，也能直接開導航。標題旁的 ⓘ 是「澳洲小百科」。

## ✅ 好盯金
- **出發前檢查清單**：證件與入境、保險與網路、錢錢、訂房與票券、行李等分類，打勾紀錄跟著帳號存，換手機登入也看得到，每個人各自一份；連續勾很多項也不會漏存。另附聖誕節店休提醒與澳洲緊急電話 000。
- **購買清單**：每個人一份想買的東西，買到了就打勾；只能改自己的，但看得到其他人的清單，方便順手幫買。
  - 輸入品項後按 Enter 會跳到「備註」（店家、數量、幫誰買，選填），再按 Enter 或「＋ 加入清單」才會加入。
  - 加入後馬上出現在清單上並自動存檔，點品項可以修改，按 ✕ 刪除。

## 💰 分帳
- **明細**：新增、修改、刪除每一筆花費或還款，可選台幣或澳幣、誰先付、哪些人分；可以依人、依類型篩選，並顯示總花費、每人平均、旅途中澳幣合計。金額欄位只能輸入數字。
- **結算**：只顯示自己要付給誰、要跟誰收多少（明細大家都看得到）；澳幣依設定的匯率換算台幣，付完錢按「已還款」會自動記一筆還款。
- **誰的錢包在哭泣**：最上面是四人消費排行榜；下面是自己分到的花費，依「機票交通、住宿、吃吃喝喝、門票活動、購物、其他」自動分類成圓餅圖，旁邊列出總額、各分類金額與比例。

## 🔒 隱私
- 網站內容全部加密，只有輸入密碼才解得開。
- 行程、記帳、清單等資料存在私人的 Google 試算表，網頁不會顯示任何人的 Email。
- 網頁設定了不讓搜尋引擎收錄，網址請不要外流。
